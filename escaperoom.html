📖 How to Play

You are locked in a room. You must find the 3-digit code to escape.

Warning: This is a logic puzzle. You will need to find tools, use them on locked objects to get clues, and solve a riddle to get the code. The puzzle changes every time!

Useful Commands:

look Shows everything in the room.

examine [object] Looks closely at an object to find clues or items.

take [item] Puts an item in your inventory.

use [item] on [object] Uses an item.

code [number] Tries to unlock the door.
